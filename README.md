# EA-Weekly-Report

EAユーザー向け週次レポート（毎週土曜・対象週の重要経済イベントと新規エントリー停止の開始目安）の自動生成リポジトリ。

- 仕様: `SPEC.md`（正本） ／ 実装引き継ぎ: `HANDOFF.md` ／ 経緯: `docs/rebuild-plan_v0.3.md`
- 成果物: `output/ea-weekly-YYYYMMDD.html`（WordPress貼り付け用断片）＋ GitHub Pagesプレビュー
- 掲載情報は民間カレンダーの公開情報に基づき機械検査を行っています。本リポジトリの内容は情報提供であり投資助言ではありません。正確性・完全性は保証されません。
